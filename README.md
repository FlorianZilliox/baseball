# Baseball, une monographie de style

Ce que le baseball a donné au vêtement de tous les jours une fois les logos retirés : des formes, des matières, et un lookbook de tenues réelles.

Site : https://florianzilliox.github.io/baseball/

Fichiers produits par `BASEBALL_WEB=1 python3 _build/build.py` ; ne pas les modifier à la main.

Chaque fait avancé vient d'une source citée, et chaque citation a été vérifiée mot pour mot dans sa page d'origine.

Une partie des photographies vient des fonds publics, en domaine public ou sous licence libre. Les autres appartiennent à leurs auteurs et sont créditées une à une dans le volet de chaque image. Pour toute demande de crédit ou de retrait, ouvrez une issue sur ce dépôt.
